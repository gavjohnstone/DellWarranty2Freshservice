Dell Warranty Sync for Freshservice

Version 1.0 · Enterprise IT

How it works

1Configure your Dell TechDirect and Freshservice credentials on the Configuration tab.
2Pick an asset type, then fetch assets and query Dell for their warranty entitlements.
3Review the comparison, then export to XLSX or apply the updates back to Freshservice.
Credentials stored in Windows Credential Manager, never in plain text.
Dry run is on by default — nothing is written until you turn it off.
Dell tags are batched and rate-limited; bearer tokens are cached for their lifetime.
Built by Gav · Enterprise IT · The Dell, Freshservice and sync engine classes are decoupled for reuse in the Admin Suite.
